# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

General media storage users needing intuitive cloud media management, fast file uploads, album organization, favoriting, and secure private storage.

## Product Purpose

GlowPic Gallery allows users to upload, organize, browse, and securely manage multimedia files in the cloud with private password-protected albums and custom collection tools.

## Positioning

A lightweight, secure personal cloud gallery featuring passcode-protected private images and albums alongside effortless album organization and favoriting.

## Operating Context

Web application environment supporting image uploading, file browsing via main explorer views, favorite tagging, private key unlocking, and profile setting adjustments.

## Capabilities and Constraints

- **Capabilities:** User authentication (login/register), media upload, album/folder creation & management, image favoriting, passcode-protected private image access, user profile & configuration views.
- **Technical Stack:** Angular 16, Tailwind CSS, RxJS, Angular Material, Docker + Nginx deployment.
- **Constraints:** Preserve the Angular 16 + Tailwind CSS architecture and existing API routes/authentication flows.

## Brand Commitments

- Product name: GlowPic Gallery / Galería de Imágenes GlowPic.
- Clean, modern media-first gallery interface.

## Evidence on Hand

- Existing Angular codebase in `src/app/` (including auth, explorer, main-page, settings-menu, home, user-profile, user-config).
- `README.md` containing product description and Docker deployment specs.
- UI assets in `src/assets/` (`uploadImage.svg`, `profile.svg`, `configuration.svg`, `Log.png`, `exit.png`).

## Product Principles

1. **Security & Privacy First:** Private images and passcode protection must feel reliable, clear, and reassuring.
2. **Media-Centric Fluidity:** Browsing, organizing, and uploading media should be frictionless and responsive across all viewports.
3. **Clarity & Simplicity:** Navigation and settings should remain clean, legible, and uncluttered.
